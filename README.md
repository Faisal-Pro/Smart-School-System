# 🎓 AI-Powered Smart School Management & Attendance System

A comprehensive school management web platform integrated with Artificial Intelligence features, including automated student academic risk assessment and a computer-vision-based attendance system.

---

## 🌟 Key Features
* **🏫 Django Web Platform:** Interactive dashboards for Students, Teachers, Parents, and Administrators.
* **📊 AI Academic Risk Assessment:** Uses machine learning models (XGBoost) to predict students at risk based on attendance, homework, and grades.
* **👁️ Smart Attendance & Proctoring:** OpenCV & MediaPipe integration for automated face detection and attendance registration.
* **📝 Assignments & Quizzes Hub:** Full portal for managing assignments, creating online quizzes, and tracking results.

---

## 🛠️ Tech Stack
* **Backend Framework:** Python (Django)
* **AI & Data Science:** XGBoost, Scikit-learn, Pandas, NumPy
* **Computer Vision:** OpenCV, MediaPipe
* **Database:** SQLite
